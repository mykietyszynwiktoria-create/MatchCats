# Sky Garden sample image assets

These two photographs were generated with the built-in image generation tool for the MatchCats prototype. They are fictional sample imagery, not verified photographs of breeders' cats. New user-created demo profiles use an empty placeholder instead. Do not infer pedigree, health or breeding suitability from these images.

The generated PNGs were encoded as JPEG at quality 85 without cropping or repainting. The application uses local files and makes no external image requests. `sky-hero.jpg` is the decorative hero photograph; `sky-portraits.jpg` contains three equal-width portraits selected with CSS background positions.

## Hero generation prompt

Use case photorealistic-natural. Asset for MatchCats Sky Garden app hero, NOT a UI screenshot. Landscape wide photograph, preferably 1536x1024. A magnificent silver tabby Maine Coon cat, healthy-looking natural anatomy, full upper body resting on a pale powder-blue linen surface, rightmost 55% of image, beautiful green eyes looking toward camera, ears fully visible. Left 45% is clean empty softly graduated light blue #d3eaff studio background for separately coded dark text overlay. Soft natural daylight, Scandinavian editorial pet portrait, subtle blurred eucalyptus on far right only, refined premium photography, soft light-blue atmosphere. Subject safe to crop to a wide banner, cat head near right upper-middle; no text, no UI, no logo, no watermark, no collar or products.

## Portrait generation prompt

Use case photorealistic-natural. ONE wide triptych photography asset, three equal width vertical panels side by side, no gaps and no borders, aspect ratio preferably 3:1, all panels showing a beautifully framed cat HEAD AND SHOULDERS at identical scale centered in its panel. Left third: silver tabby Maine Coon longhair with green eyes. Middle third: cream white blue-point bicolor Ragdoll longhair with blue eyes. Right third: plush gray British Shorthair round face with amber eyes. Each cat face fully visible including ears, each panel softly lit natural editorial photograph on a light blue/cream Scandinavian interior backdrop. Main faces occupy central 65% panel width, facial features within upper half to allow responsive crop. The asset is intended as three photo cards cropped by CSS in a professional cat breeder demo application. Realistic anatomy, premium sharp photographic texture. NO text, no labels, no icons, no UI, no watermark, no collars, no hands, no medical or certification graphics.
